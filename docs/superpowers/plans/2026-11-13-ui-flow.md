# UI Flow (tab YouTrack) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Từ một ticket YouTrack (AC, rule, link Zeplin), AI chạy một lần ra dữ liệu luồng UI; code thuần vẽ thành file `uiflow-<ticket>.html` tự chứa, xem được ở 2 chế độ (toàn cục, prototype), kéo thả sửa luồng và cập nhật lại lên ticket kèm comment.

**Architecture:** Một engine JS thuần (`web/public/uiflow.js`, không dependency) dùng cho cả dashboard và file xuất. Backend (`telegram_dashboard/uiflow.py` + route trong `yt_dashboard.py`) lo: lượt AI → JSON đã kiểm schema, ghép file HTML (khung + engine + JSON), rút JSON từ file đính kèm, so sánh hai bản, tải lên / xoá / comment. Dashboard không bao giờ chạy file đính kèm: chỉ đọc khối JSON rồi vẽ bằng engine của app.

**Tech Stack:** Python 3 / FastAPI / pydantic / httpx (đã có); JS thuần + SVG + pointer events; React 19 + TanStack Query cho phần vỏ; pytest; Playwright.

**Spec:** `docs/superpowers/specs/2026-11-13-ui-flow-design.md`

## Global Constraints

- Không thêm dependency (Python lẫn npm).
- Tên file đính kèm: đúng `uiflow-<ISSUE>.html` (vd. `uiflow-VA-123.html`). Chỉ file tên này được tool đọc / xoá.
- Khối dữ liệu trong file: `<script type="application/json" id="uiflow-data">…</script>`, mọi `<` trong JSON ghi thành `\u003c`.
- File xuất không tải gì từ mạng.
- Mọi chữ lấy từ dữ liệu vẽ qua `textContent`, không `innerHTML`.
- Text ticket đưa vào AI bọc random tag "dữ liệu KHÔNG tin cậy" (dùng `_ticket_json` / `link_block` sẵn có); lượt này không shell, không đọc file; chỉ được 3 tool đọc Zeplin khi ticket có link Zeplin.
- Sau mỗi lần ghi lên YouTrack: `svc.stale(id)`.
- Lỗi 401 / 403 / mạng phải lên UI; mutation frontend có `onError` + `errorText`.
- Chuỗi UI mới: key tiếng Việt qua `useT()`, bản Anh trong `web/src/lib/i18n/en/yt.ts`. Cỡ chữ theo token, không `text-[Npx]` (riêng `uiflow.js` tự mang CSS vì phải chạy trong file độc lập).
- Dev / test: không build đè `web/out`, không đụng `:8765`; e2e chạy trên bản copy ở scratchpad. Subagent luôn truyền `model`.
- v1 mobile first: khung màn 390 × 844 (đơn vị canvas).
- v1 là wireframe (tên màn + danh sách nút). Ảnh Zeplin thật **ngoài plan**: Task 0 chỉ ghi lại kết quả thử, rồi hỏi lại chủ dự án.
- Trong phạm vi thêm (đã đề xuất, đi kèm design): truy ngược AC (`ac`), soát lỗ hổng luồng, link tới một màn. Ngoài phạm vi: nhánh trạng thái chọn trong prototype, checklist test, render lại giữ chỗ, gộp nhiều ticket, xuất PNG, ghi chú ghim.

```python
NAME = "uiflow-{issue}.html"          # tên file đính kèm
MAX_SCREENS, MAX_ITEMS, MAX_LINKS = 60, 20, 300

class Item(BaseModel):   id: str; label: str (1..80)
class Screen(BaseModel): id: str; title: str (1..80); kind: Literal["screen","popup","sheet","toast"] = "screen"
                         parent: str | None = None; x: float | None = None; y: float | None = None
                         zeplin: str = ""  (chỉ nhận khi khớp providers.ZEPLIN, ngược lại "")
                         ac: str = "" (<=40); items: list[Item]
class Link(BaseModel):   src: str ("screenId" hoặc "screenId.itemId"); to: str
                         act: Literal["navigate","open","back","close"] = "navigate"
                         when: str = "" (<=80); ac: str = "" (<=40)
class Flow(BaseModel):   v: Literal[1] = 1; ticket: str; rev: int = 0; device: Literal["mobile"] = "mobile"
                         screens: list[Screen]; links: list[Link]

def clean(raw: dict, ticket: str) -> Flow
def build_html(flow: Flow, engine: str) -> str
def extract(html: str) -> Flow | None
def changes(old: Flow | None, new: Flow) -> list[str]
AI_FLOW: str
```

```python
def test_clean_drops_broken_links_and_sets_ticket():

            u.clean(bad, "VA-1")

def test_clean_keeps_only_zeplin_urls_and_unknown_parent_becomes_none():
```

### Task 3: Service + route lưu / đọc flow trên ticket

**Files:**
- Modify: `telegram_dashboard/yt_dashboard.py` (`attach` dòng 744; thêm model + route cạnh `/issue/comment` dòng ~1368), `telegram_dashboard/app.py:1264` (caller `attach`, không đổi hành vi)
- Test: `tests/test_yt_dashboard.py`

**Interfaces:**
- Consumes: `uiflow.clean / build_html / extract / changes / NAME` (Task 1).
- Produces:

```python
# YouTrackDashboard
async def upload(self, issue: str, name: str, data: bytes, *, mime: str) -> str      # id file mới
async def attach(self, issue: str, path) -> None                                     # giữ nguyên, gọi upload(mime="image/jpeg")
async def detach(self, issue: str, att: str) -> None                                 # DELETE …/attachments/{att}
async def flow_file(self, issue: str) -> tuple[str, Flow | None] | None             # (att id, flow) của uiflow-<issue>.html mới nhất; None khi chưa có

class FlowSave(BaseModel): id: str; flow: dict; base: str | None = None             # base = att id bản đã mở

GET  /api/yt/flow?issue=VA-1  -> {"att": str | None, "flow": dict | None, "broken": bool}
POST /api/yt/flow  (FlowSave) -> {"att": str, "rev": int, "changes": list[str], "warn": str}
```

- `flow_file`: đọc `attachments(id,name,created,removed)` của ticket, lọc tên đúng `NAME`, bỏ `removed`, lấy `created` lớn nhất; tải bytes theo cách của `svc.file` (cùng kiểm host + `MAX_FILE`), `extract()`.
- `GET /flow`: chưa có file → `{att: None, flow: None, broken: False}`; có file nhưng `extract` ra `None` → `broken: True`.
- `POST /flow` theo đúng thứ tự:
  1. `clean(body.flow, issue)` (lỗi → 400 "UI flow không hợp lệ").
  2. `cur = await svc.flow_file(issue)`; `cur_id = cur[0] if cur else None`; `cur_id != body.base` → **409** "UI flow vừa được người khác cập nhật — mở lại để xem bản mới". Không ghi gì.
  3. `ch = changes(cur[1] if cur else None, new)`; rỗng → 400 "Không có thay đổi".
  4. `new.rev = (cũ.rev nếu có, không thì 0) + 1`; đọc engine từ `settings.static_dir / "uiflow.js"` (thiếu → 503 "Thiếu uiflow.js — build lại web"); `upload(issue, NAME, html.encode(), mime="text/html")`.
  5. Có bản cũ: `detach(issue, cur_id)`. Lỗi → **không raise**, ghi `warn = "Đã tải bản mới nhưng chưa xoá được file cũ: …"`.
  6. Comment: dòng đầu `UI flow cập nhật (rev {n}) — tệp đính kèm {NAME}` (rev 1: `UI flow mới (rev 1) — …`), sau đó mỗi thay đổi một dòng `- …`, tối đa 20 dòng, dư thì `- … và {k} thay đổi khác`. Lỗi → nối vào `warn` ("…chưa post được comment: …"), không raise.
  7. `svc.stale(issue)`; trả kết quả.
